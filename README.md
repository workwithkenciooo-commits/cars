# AERO GT

Scroll-animated landing page (React + Vite + Tailwind).

## Run locally
    npm install
    npm run dev

## Deploy to GitHub Pages
1. Create an empty repo on GitHub and push this folder to the `main` branch.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and publishes on every push.
   Site: https://YOUR-USERNAME.github.io/YOUR-REPO/
